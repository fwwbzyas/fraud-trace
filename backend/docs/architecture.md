## 技术栈详细说明

### 表现层
- **前端框架**: React 18 + TypeScript + Ant Design
- **状态管理**: Redux Toolkit / Zustand
- **路由管理**: React Router v6
- **图表组件**: ECharts / D3.js
- **构建工具**: Vite / Webpack

### 应用服务层
- **后端框架**: Spring Boot 3.x + Spring Security
- **API网关**: Spring Cloud Gateway
- **服务发现**: Eureka / Consul
- **配置中心**: Spring Cloud Config
- **负载均衡**: Ribbon / Spring Cloud LoadBalancer

### 数据计算层
- **计算引擎**: Apache Spark 3.x (Scala/Java)
- **流处理**: Spark Streaming + Kafka
- **机器学习**: Spark MLlib
- **任务调度**: Apache Airflow / Quartz
- **资源管理**: YARN / Kubernetes

### 数据层
- **关系数据库**: PostgreSQL 14+ (主从复制)
- **分析数据库**: ClickHouse (列式存储)
- **缓存系统**: Redis Cluster
- **消息队列**: Apache Kafka
- **文件存储**: HDFS / MinIO

### 监控运维
- **应用监控**: Spring Boot Actuator + Micrometer
- **日志收集**: ELK Stack (Elasticsearch + Logstash + Kibana)
- **链路追踪**: Zipkin / Jaeger
- **容器化**: Docker + Kubernetes
- **CI/CD**: Jenkins / GitLab CI

## 数据流向

1. **数据采集**: 银行核心系统 → Kafka → Spark Streaming
2. **实时计算**: Spark → Redis (缓存) → 前端展示
3. **批量计算**: ClickHouse → Spark Batch → PostgreSQL
4. **结果查询**: PostgreSQL → Spring Boot → React前端

## 安全架构

- **认证授权**: JWT + OAuth 2.0 + RBAC
- **数据加密**: AES-256 + RSA + TLS 1.3
- **网络安全**: VPN + 防火墙 + WAF
- **审计日志**: 操作日志 + 访问日志 + 数据变更日志

## 高可用设计

- **数据库**: 主从复制 + 读写分离
- **应用服务**: 集群部署 + 负载均衡
- **计算引擎**: Spark集群 + 故障转移
- **缓存系统**: Redis哨兵 + 集群模式
